# Jot UX agents report, 3 October 2026

Branch `app-design-pass` (commit 0130b14). Tested hands-on in the iOS Simulator:
- iPhone 17 (iOS 26), light and dark mode, default and largest accessibility text size.
- iPhone SE (3rd generation), a 4.7-inch screen.

Driven with tap, long-press, typing and screenshots, plus `simctl` for appearance, text
size and permissions. No accessibility-tree tool (XcodeBuildMCP or idb) was installed, so the
VoiceOver findings come from the code, not from a live tree.

This is simulated testing. Check the top issues with real TestFlight testers.

## The app in one paragraph

Jot is a hold-to-talk capture app.
- **The core loop:** hold the orb, speak, let go. The words are transcribed on the phone,
  sorted into a note, task, reminder or event (on-device by default), and land on Today's
  timeline.
- **Repeat use:** checking Today ("Next: …"), clearing what's still open, and finding things
  in the Inbox agenda.
- **Main flows:** onboarding (5 steps), Today, Inbox, item detail with follow-ups, Settings
  (a sheet), and the capture stage.
- **Ways back into the app:** reminder notifications, the morning brief, widgets, the Live
  Activity, Siri, Control Center and the Action Button.

## Top 10 issues

Ranked by impact multiplied by the number of agents that flagged them.

### 1. Onboarding falls out of sync on fast taps and skips the name step
Flagged by: First-Timer, Edge-Case, Churn.

**Screenshot:** `screenshots/onb-desync.png`. The dots show step 4 while the page shows
step 2. The next tap jumped to step 5, so "Hold the orb" and the name step were never seen,
and the name typed went nowhere.

**File:** `Jot/Views/Onboarding/OnboardingView.swift`. The Next button changes `page` while
the paging `TabView` is still animating, and the pager drops the change.

**Fix:** ignore taps until the page settles, or drive the pages yourself instead of with a
swipe pager.
```swift
@State private var isTurning = false
Button { guard !isTurning else { return }
    isTurning = true
    withAnimation(animation) { page += 1 } completion: { isTurning = false }
}
```

### 2. Today and Inbox break at the largest text sizes
Flagged by: Accessibility, Commuter.

**Screenshots:** `screenshots/today-ax5.png`, `screenshots/inbox-ax5.png`.
- The Today header is clipped off the left edge ("aturday", "ood afternoon").
- Times truncate to "9:…" and "8:…".
- The tab labels, the week strip and the capture stage use fixed point sizes (30
  `.font(.system(size:))` calls in `Jot/Views`), so they don't grow.

**Files:**
- `TodayView.swift` (`RailRow`, the "earlier" header): `.fixedSize()` on "Move to tomorrow"
  forces the header wider than the screen.
- `InboxView.swift` (`InboxCard`, `WeekStrip`).
- `Chrome.swift` (`BottomBar`).

**Fix:** at accessibility sizes, stack the time above the title, and scale the column width.
```swift
@Environment(\.dynamicTypeSize) private var size
@ScaledMetric(relativeTo: .footnote) private var timeColumn: CGFloat = 64
// if size.isAccessibilitySize { VStack { time; title } } else { HStack { … } }
```
Also put the "Still open from earlier" header in a `ViewThatFits` (HStack, then VStack), and
replace fixed sizes with text styles (for example `.caption2.weight(.semibold)` for the tab
labels).

### 3. Permission prompts arrive at the wrong moment
Flagged by: Churn, First-Timer, Edge-Case.

**Notifications.** The system prompt appears as soon as Today opens, with no context
(`screenshots/today-ax5.png` before it was answered).

**Microphone.** On the first hold, the screen goes black with "Listening", then the system
microphone prompt appears over it. After letting go, "Listening" stays behind the prompt
(`screenshots/first-hold.png`, `screenshots/first-hold-after.png`).

**Files:**
- `Jot/Services/ReminderScheduler.swift` (`mayPrompt` in `refill`).
- `Jot/Services/CaptureController.swift` (`beginCapture`).

**Fix:**
- Ask for notifications when the first reminder is saved, from the confirmation card: "Want
  a nudge at 2:00 PM? Allow notifications".
- In `beginCapture`, if microphone or speech access is `.notDetermined`, request it before
  switching to the stage. Show the stage only once audio is actually running.

### 4. Orange text and orange buttons fail contrast
Flagged by: Accessibility, UI Designer.

- `#FF6B35` text on the background is **2.54:1**. That covers the "now" time, Done, and
  Privacy policy.
- White on `#FF6B35` (Next, Start jotting) is **2.84:1**.
- WCAG needs 4.5:1 for small text and 3:1 for large text.

**File:** `Shared/Brand.xcassets` and `Shared/DesignSystem.swift`.

**Fix:** keep the bright orange for the orb, which isn't text. Add `JotAccentText` =
`#C2410C`, which gives 4.63:1 on the background and 5.18:1 with white text on it. Use it for
orange text and for primary button fills.

### 5. The morning brief is off by default and never offered
Flagged by: Retention, Strategist.

`MorningBrief.isEnabled` defaults to false, and onboarding doesn't mention it. It's the
app's best daily trigger.

**File:** `Jot/Views/Onboarding/OnboardingView.swift` (`PermissionsPage`) and
`Jot/Services/MorningBrief.swift`.

**Fix:** add a "Brief me at 8:00 AM" switch to the permissions step, on by default and
paired with the notifications Allow.

### 6. VoiceOver can't tell an item's type on Today or in Inbox day sections
Flagged by: Accessibility.

After the redesign, the type is shown only by `KindNode`, which is
`accessibilityHidden(true)`. Rows in Inbox day sections show details instead of the type
word.

**Files:** `TodayView.swift` (`ItemLines`, `RailRow`), `InboxView.swift` (`InboxCard`).

**Fix:**
```swift
.accessibilityElement(children: .combine)
.accessibilityLabel("\(item.kind.label), \(item.title)")
```

### 7. A short tap gives a technical error instead of teaching "hold"
Flagged by: First-Timer, Edge-Case, Churn.

**Screenshot:** `screenshots/quick-tap.png`: "Can't record right now: no microphone input".
The simulator has no microphone, but nothing distinguishes a too-short tap, and the wording
is technical (`MicAudioSource.swift:25`).

**Fix:** if the orb is released in under 0.4 s, don't record; show "Hold the orb while you
talk". Reword microphone errors as "Jot can't hear the microphone. Check that nothing else is
using it."

### 8. The detail screen still uses the old card style
Flagged by: UI Designer, Edge-Case.

**Screenshot:** `screenshots/detail.png`.
- The When card and the bright blue "Today 7:30 PM" don't match the redesign.
- The Repeat options run off the card edge ("Yearly" is hidden).

**File:** `Jot/Views/ItemDetailView.swift`.

**Fix:**
- Show When and Repeat as plain rows: "When: Today, 7:30 PM" and "Repeat: Never".
- Make Repeat a `Menu` instead of a row of options.
- Keep the serif "What you said" quote, which is the screen's best element.

### 9. Several tap targets are smaller than 44 pt
Flagged by: Accessibility, Commuter.

- The profile badge is 38 pt (`Chrome.swift:31`).
- Compact buttons such as "Move to tomorrow" and "Allow" are about 32 pt tall
  (`JotButtonStyle`, compact).
- The detail close button is 28 pt (`ItemDetailView.swift:165`).

**Fix:** `.frame(minWidth: 44, minHeight: 44).contentShape(.rect)` on each, keeping the same
look.

### 10. The Apple Intelligence dependency is silent
Flagged by: Churn, First-Timer, Strategist.

If Apple Intelligence is off, every capture quietly stays a note. Only Settings explains why.

**Files:** `Jot/Views/SmartSortingCard.swift`, `Jot/AI/OnDeviceClassifier.swift`.

**Fix:**
- In onboarding, show the status and offer Claude in the same card.
- After the first capture that couldn't be sorted, show a one-time card: "Turn on Apple
  Intelligence or choose Claude to sort automatically."

## Stickiness plan

These are the three changes most likely to bring people back daily.

1. **Morning brief on by default** (issue 5). A notification at 8 AM, "Good morning, James:
   2 events, 3 reminders", opens Today. This is the trigger the Hook model is missing.
2. **An evening "close the day" nudge.** At 8 PM, if anything is still open: "3 things still
   open". Give it a **Move to tomorrow** notification action, using the existing
   `ItemActions.moveToTomorrow`. That's a one-tap reward that ends the day tidy and makes the
   loop daily.
3. **Make Jot where the day lives.**
   - Save events to Calendar and reminders to Reminders.
   - Let people check items off from interactive widgets.
   - Add a Lock Screen widget showing "Next: …".

   The more of the day Jot holds, the more there is to come back to. It also builds on the
   name and follow-ups people have already added.

## Accessibility failures

- Clipping at the largest text sizes, and the time column truncating (issue 2).
- 30 fixed font sizes that ignore the user's text size.
- Contrast:

  | Pair | Ratio |
  |---|---|
  | Orange text on the background | 2.54:1 |
  | White on orange | 2.84:1 |
  | Amber reminder node, a non-text shape | 2.47:1 (passes the 3:1 non-text rule only for other colours) |
  | The rail line, decorative | 1.51:1 |

- Item type not announced to VoiceOver (issue 6).
- Tap targets under 44 pt (issue 9).
- **Passes:** Reduce Motion is respected (the now-line pulse, transitions, the orb), swipe
  actions are exposed as accessibility actions, and the orb has a VoiceOver tap-to-start
  action.

## Quick wins (under an hour each)

- [ ] Ignore Next taps while a page is turning (issue 1).
- [ ] `JotAccentText` colour for orange text and buttons (issue 4).
- [ ] VoiceOver label with the type on rows (issue 6).
- [ ] 44 pt minimum tap targets (issue 9).
- [ ] Short-tap hint and plain-language microphone errors (issue 7).
- [ ] `@ScaledMetric` time column, and no `.fixedSize()` on "Move to tomorrow" (part of issue 2).
- [ ] Morning brief switch in onboarding, on by default (issue 5).

## What's already working well

- **The capture stage.** A black screen with large live words is a memorable, single bold
  moment.
- **On-device sorting.** It works offline with nothing sent anywhere, and dates are worked
  out in code, so "Thursday at two" comes out as Thursday (8 tests).
- **The Today header** answers "what now?" ("Next: Dinner with Sam at 7:30 PM"). The "Still
  open from earlier" fold keeps the timeline honest.
- **The Inbox agenda**, with the two-week strip and day sections, feels like a calendar
  without being one.
- **The denied-microphone path** recovers well: a plain message and an **Open Settings**
  button (`screenshots/mic-denied.png`).
- **Dark mode** (true black, with orange only for live states) and the new Appearance
  setting.
- **Performance:** first frame under 0.5 s, a short launch animation, and no app errors or
  crashes in the simulator logs.
- **The empty state** says exactly what to do ("Hold the orb and say what's on your mind").
